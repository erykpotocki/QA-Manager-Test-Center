# QA Manager v0.2

## W trakcie

- Admin i Lider mogą utworzyć host synchronizacji.
- Admin i Lider mogą wygenerować plik połączenia.
- Tester może wyłącznie dołączyć do istniejącego hosta.
- Po utworzeniu hosta aplikacja uruchamia się ponownie automatycznie.
- Po wczytaniu pliku połączenia aplikacja uruchamia się ponownie automatycznie.
- Po przełączeniu na tryb lokalny aplikacja uruchamia się ponownie automatycznie.
- Dodano ręczne odświeżanie danych z menu profilu oraz klawiszem F5.
- Podczas odświeżania wyświetlany jest animowany wskaźnik.
- Dodano neutralne katalogi demonstracyjne TEST PROJECT — ENGLISH i TEST PROJECT — POLISH.
- Zaimportowano 504 przypadki, 1212 kroków, opisy, warunki wstępne, oczekiwane wyniki i metadane.
- Zachowano przejrzystą kolejność neutralnych obszarów demonstracyjnych płatności.
- Dodano edycję szczegółów przypadków testowych wraz z automatycznym zapisem.
- Główne gałęzie szkieletu mogą być zmieniane przez Admina lub Lidera.
- Usunięcie dużej gałęzi wymaga zatwierdzenia przez Admina lub Lidera w centrum powiadomień.
- Ujednolicono podstawowy wygląd, wyrównanie i typografię przycisków w obu motywach.
- Uzupełniono angielskie tłumaczenia przypisań, powiadomień, dashboardu i wznawiania sesji.
- Przycisk wykonywania przypisanych testów respektuje wybrany kolor dominujący.
- Pasek ról wykorzystuje wolne miejsce i ukrywa role pod wielokropkiem dopiero przy braku przestrzeni.
- Usunięto pętlę pomiędzy ostatnim zbiorem przypisanych testów a ekranem podsumowania.
- README rozszerzono o aktualne zrzuty interfejsu i opis neutralnych danych demonstracyjnych.

Ten dokument jest aktualizowany po każdej ukończonej zmianie należącej do v0.2.
